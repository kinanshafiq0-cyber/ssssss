## 📦 التثبيت

### المتطلبات
- Node.js v18+
- Discord Bot Token

### الطريقة السريعة (Windows)
1. شغّل `install.bat`
2. عدل ملف `.env`
3. شغّل `start.bat`

### الطريقة اليدوية
```bash
npm install
cp .env.example .env
# عدل ملف .env
npm start
```

### على الاستضافة (Render, Railway, Replit, إلخ)
```bash
npm install
# حط المتغيرات البيئية في لوحة الاستضافة:
# TOKEN, DASHBOARD_USERNAME, DASHBOARD_PASSWORD, OWNER_ID
npm start
```

## 🔧 أوامر الدسكورد

- `/protection on [system]` - تفعيل الحماية (الأونر فقط)
- `/protection off [system]` - إيقاف الحماية (الأونر فقط)

## 🌐 لوحة التحكم

افتح المتصفح على `http://localhost:3000` وسجل الدخول باسم المستخدم وكلمة المرور.
